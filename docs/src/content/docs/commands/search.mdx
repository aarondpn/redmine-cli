## General search

```bash
redmine search <query> [flags]
```

| Flag | Description |
|------|-------------|
| `--project`     | Limit to a project (defaults to the configured default project) |
| `--scope`       | Search scope: `all`, `my_projects`, `bookmarks`, `subprojects` (`all`, `my_projects`, and `bookmarks` ignore the default project) |
| `--all-words`   | Require all query words to match (default `true`); use `--all-words=false` to match any word |
| `--titles-only` | Search titles only |
| `--open-issues` | Only return open issues |
| `--attachments` | Attachment search: `0`, `1`, `only` |
| `--issues`      | Include issues |
| `--news`        | Include news |
| `--documents`   | Include documents |
| `--changesets`  | Include changesets |
| `--wiki-pages`  | Include wiki pages |
| `--messages`    | Include forum messages |
| `--projects`    | Include projects |
| `--limit`       | Maximum results |
| `--offset`      | Result offset |
| `-o, --output`  | Output format |

<Aside type="caution" title="Default project">
  If the active profile has a default project and you don't pass `--project`,
  search is limited to that project (plus its subprojects with
  `--scope subprojects`). After a successful search the CLI prints a one-line
  notice to `stderr` when this happens. It is printed in JSON mode too, since
  stdout stays clean for `-o json`:

  ```text
  Searching project "myproject" (default project). Use --scope all to search all projects.
  ```

  Use `--scope all` to search every project you can see, or pass `--project`
  explicitly to pick one (which also silences the notice). The notice is not
  shown for `--scope all`, `--scope my_projects`, `--scope bookmarks` (Redmine
  ignores the project for these), or the interactive `browse`.
</Aside>

Without type flags, Redmine searches every resource type, including
changesets. Add `--issues`, `--wiki-pages`, etc. to cut the noise.

## Typed search

Search specific resource types directly:

```bash
redmine search issues   <query> [flags]
redmine search projects <query> [flags]
redmine search wiki     <query> [flags]
redmine search news     <query> [flags]
redmine search messages <query> [flags]
```

<Aside type="tip">
  Typed search is equivalent to general search with the matching `--<type>` flag, but keeps the invocation shorter and the intent obvious in scripts.
</Aside>

## Interactive browse

```bash
redmine search browse <query> [flags]
```

Opens search results in an interactive terminal browser.

Press `o` to open the selected result in your web browser. Issue results open on your configured Redmine server. Other results use the URL reported by the server: only absolute `http`/`https` URLs are opened, and a URL on a different host is first shown in full in the status line and only opened when you press `o` again.
