## log

```bash
redmine time log [flags]
```

| Flag | Description |
|------|-------------|
| `--issue`    | Issue ID |
| `--project`  | Project (name or identifier) |
| `--hours`    | Hours spent — <Badge text="required" variant="danger" /> |
| `--activity` | Activity type (name or ID) |
| `--comment`  | Description of work |
| `--date`     | Date (YYYY-MM-DD or `today`, default: today) |
| `--user`     | Log on behalf of another user (`me`, login, name, or ID). Names are matched against the members of `--project`, or of the issue's project with `--issue` |
| `--custom-field` | Custom field value as `name=value` or `id=value` (repeatable; repeat a field for multi-value fields, `name=` clears it). See [custom field values](/commands/issues/#custom-field-values) |

<Tabs syncKey="time-log">
  <TabItem label="Basic">
    ```bash
    redmine time log --issue 123 --hours 1.5 --activity Development --comment "Bug fix"
    ```
  </TabItem>
  <TabItem label="Custom fields">
    ```bash
    redmine time log --issue 123 --hours 2 \
      --custom-field "Billing Code=ACME-42" \
      --custom-field Tags=Onsite --custom-field Tags=Overtime
    ```
  </TabItem>
  <TabItem label="On behalf of">
    ```bash
    redmine time log --issue 123 --hours 1 --user jsmith --comment "Pair work"
    ```
  </TabItem>
</Tabs>

<Aside type="caution">
  `--user` requires admin privileges or the "Log time for other users" permission on the Redmine server. The target user must also be a member of the project with the "Log spent time" permission, otherwise Redmine returns a validation error (`User is invalid`).
</Aside>

<Aside type="tip" title="Required custom fields">
  If the server defines required time entry custom fields, `time log` fails with `validation_failed` until you pass them with `--custom-field`. Looking fields up by name needs admin rights; otherwise use the numeric IDs from `redmine time list --limit 1 --jq '.[0].custom_fields'`.
</Aside>

## list

```bash
redmine time list [flags]
```

| Flag | Description |
|------|-------------|
| `--project`    | Filter by project |
| `--user`       | Filter by user: `me`, name, login, or ID. With `--project`, names are matched against project members first (no admin rights needed) |
| `--issue`      | Filter by issue ID |
| `--activity`   | Filter by activity (name or ID) |
| `--from`       | Start date (YYYY-MM-DD or `today`) |
| `--to`         | End date (YYYY-MM-DD or `today`) |
| `--limit`      | Maximum number of results |
| `--offset`     | Result offset for pagination |
| `-o, --output` | Output format |

<Tabs syncKey="time-list">
  <TabItem label="This week">
    ```bash
    redmine time list --user me --from 2024-01-15 --to 2024-01-19
    ```
  </TabItem>
  <TabItem label="By issue">
    ```bash
    redmine time list --issue 123
    ```
  </TabItem>
</Tabs>

## get

```bash
redmine time get <id> [flags]
```

Aliases: `show`, `view`.

## update

```bash
redmine time update <id> [flags]
```

| Flag | Description |
|------|-------------|
| `--hours`    | New hours |
| `--activity` | New activity (name or ID) |
| `--comment`  | New comment |
| `--date`     | New date (YYYY-MM-DD or `today`) |
| `--custom-field` | Custom field value as `name=value` or `id=value` (repeatable; repeat a field for multi-value fields, `name=` clears it). See [custom field values](/commands/issues/#custom-field-values) |

## delete

<Badge text="destructive" variant="caution" />
```bash
redmine time delete <id> [flags]
```

| Flag | Description |
|------|-------------|
| `-f, --force` | Skip confirmation prompt |

## summary

```bash
redmine time summary [flags]
```

Displays a summary of time entries grouped by project and activity. Accepts the same filter flags as [`list`](#list).

<Aside type="tip">
  Combine `summary` with `--from today --user me` for a quick end-of-day breakdown of your own work.
</Aside>
