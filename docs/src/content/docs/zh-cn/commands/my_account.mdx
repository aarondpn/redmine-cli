`my-account` 命令对应 Redmine 的 `/my/account.json` 接口，是 Redmine 提供给非管理员用户的唯一写入路径——任何能完成身份验证的用户都可以在无需管理员协助的情况下更新自己的名、姓、邮箱、语言、通知设置和偏好设置。

<CardGrid>
  <LinkCard title="get"    href="#get"    description="查看自己的账户详情，包括 api_key 和自定义字段。" />
  <LinkCard title="update" href="#update" description="更新自己的姓名、邮箱、语言、通知或偏好设置。" />
</CardGrid>

<Aside type="note" title="与 users me 的区别">
  `users me` 返回 `/users/current.json` 的结果，与其他管理员看到的用户记录相同。`my-account get` 返回 `/my/account.json`，还会额外返回你的 **API 密钥** 和账户上的 **自定义字段**，并与可写命令 `my-account update` 配对使用。
</Aside>

## get

```bash
redmine my-account get [flags]
```

别名：`show`、`view`。显示 ID、登录名、姓名、邮箱、管理员标志、状态、邮件通知偏好、API 密钥（如有）、自定义字段、创建/最近登录时间戳。Redmine 在 `/my/account.json` 中从不返回 `status`，因此 Status 行显示 `unknown`，JSON 输出中也不会包含 `status` 键。

| 标志 | 描述 |
|------|------|
| `-o, --output` | 输出格式 |

## update

```bash
redmine my-account update [flags]
```

别名：`edit`。更新自己的账户。仅显式设置的标志会发送到服务器——局部更新不会覆盖其他字段。

| 标志 | 描述 |
|------|------|
| `--firstname`         | 新的名 |
| `--lastname`          | 新的姓 |
| `--mail`              | 新的邮箱地址 |
| `--language`          | 界面语言代码，例如 `en`、`de` 或 `pt-BR`；留空表示使用服务器默认值。只写：没有任何 API 响应会返回该值 |
| `--mail-notification` | 邮件通知偏好：`all`、`selected`、`only_my_events`、`only_assigned`、`only_owner`、`only_my_watches`（Redmine 7.0+）、`none`。`selected` 针对 `--notified-project` 指定的项目发送通知 |
| `--notified-project`  | 在 `--mail-notification selected` 下接收全部通知的项目（标识符、名称或 ID，可重复）。仅统计你是成员的项目。替换当前集合；`""` 表示清空。只写：没有任何 API 响应会返回该值 |
| `--pref`              | 偏好设置，格式为 `key=value`（可重复），例如 `no_self_notified=1`、`hide_mail=1`、`time_zone=Berlin`、`comments_sorting=desc`。只写：没有任何 API 响应会返回该值。可用的键参见[用户偏好设置](/zh-cn/commands/users/#偏好设置) |
| `--custom-field` | 自定义字段值，格式为 `name=value` 或 `id=value`（可重复；多值字段请对同一字段重复使用该标志，`name=` 表示清空）。参见[自定义字段值](/zh-cn/commands/issues/#自定义字段值) |

```bash
# 只接收两个项目的通知，并且不接收关于自己更改的通知
redmine my-account update --mail-notification selected --notified-project web --notified-project api --pref no_self_notified=1

# 界面语言和时区
redmine my-account update --language de --pref time_zone=Berlin
```

`no_self_notified` 是偏好设置而不是用户属性，因此通过 `--pref` 设置。

<Aside type="note" title="自定义字段">
  Redmine 只会应用管理员设为用户可编辑的自定义字段。按名称查找字段需要管理员权限；否则请通过 `redmine my-account get --jq '.custom_fields'` 获取数字 ID。
</Aside>

<Aside type="caution" title="无需管理员权限">
  与 `users update` 不同，`my-account update` 不需要管理员权限——所有已认证的用户都能修改自己的资料。请务必确认使用的 API 密钥属于你想要修改的账户。
</Aside>
