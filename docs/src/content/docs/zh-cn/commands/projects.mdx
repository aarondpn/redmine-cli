## list

```bash
redmine projects list [flags]
```

| 标志 | 描述 |
|------|------|
| `--status`     | 状态过滤：`active`、`closed`、`all` 或数字状态（`1` 活动，`5` 已关闭）。默认：Redmine 只列出活动项目 |
| `--sort`       | 排序方式，例如 `name` 或 `created_on:desc` |
| `--filter`     | 原始 Redmine 过滤条件，格式为 `key=value`（可重复），例如 `--filter name='~web'`、`--filter created_on='>=2026-01-01'` |
| `--include`    | 附加数据，可重复或以逗号分隔：`trackers`、`issue_categories`、`enabled_modules`、`time_entry_activities`、`issue_custom_fields` |
| `--limit`      | 最大结果数 |
| `--offset`     | 分页偏移量 |
| `-o, --output` | 输出格式：`table`、`json` |

表格视图始终显示 `ID, Identifier, Name, Status, Public`。如需查看通过 `--include` 请求到的额外字段，请使用 `--output json`。

<Aside type="caution" title="已关闭和已归档的项目会被隐藏">
  自 Redmine 4.1 起，未指定状态时项目列表**只返回活动项目**，因此除已归档项目外，已关闭的项目也会被隐藏。使用 `--status closed` 或 `--status all` 可查看已关闭的项目。REST API 从不列出已归档的项目（管理员也不例外），因此 `--status archived` 和 `--status 9` 会被拒绝；`--status all` 列出活动和已关闭的项目。
</Aside>

`--filter` 会像 [`issues list`](/zh-cn/commands/issues/#list) 一样原样传递 Redmine 查询参数：`name`、`description`、`created_on`、`updated_on` 等普通过滤条件（可使用 Redmine 运算符），以及通用的 `f[]`/`op[]`/`v[]` 语法（以 `[]` 结尾的键可重复以发送多个值）。如果 `--filter` 的键与某个专用标志发送的参数相同（例如 `status`），则以 `--filter` 的值为准。使用 `f[]` 时，Redmine 只应用 `f[]` 中列出的过滤条件；其他标志（例如 `--status`）设置的过滤条件会被丢弃。

```bash
redmine projects list --status all --sort name
redmine projects list --filter name='~web' --filter created_on='>=2026-01-01'
```

## get

```bash
redmine projects get <identifier> [flags]
```

别名：`show`、`view`。

| 标志 | 描述 |
|------|------|
| `--include`    | 附加数据，可重复或以逗号分隔：`trackers`、`issue_categories`、`enabled_modules`、`time_entry_activities`、`issue_custom_fields` |
| `-o, --output` | 输出格式 |

详情视图会在响应包含相关字段时显示主页、默认指派人、默认版本、已启用模块以及项目自定义字段值。

## create

```bash
redmine projects create [flags]
```

| 标志 | 描述 |
|------|------|
| `--name`               | 项目名称 — <Badge text="必填" variant="danger" /> |
| `--identifier`         | URL 友好的标识符 — <Badge text="必填" variant="danger" /> |
| `--description`        | 项目描述 |
| `--description-file`   | 从文件读取描述（`-` 表示读取标准输入）；与 `--description` 互斥；空文件或只含空白的文件会被拒绝 |
| `--homepage`           | 项目主页 URL |
| `--public`             | 将项目设为公开 |
| `--parent`             | 父项目标识符、名称或数字 ID |
| `--inherit-members`    | 继承父项目的成员 |
| `--default-assignee`   | 新工单的默认指派人（登录名、姓名或数字 ID） |
| `--default-issue-query` | 作为项目默认问题列表的公共全局查询（名称或 ID，参见 [`queries list`](/zh-cn/commands/queries/)）。<Badge text="Redmine 5.0+" variant="note" /> 旧版本会忽略该设置；`projects get` 不会显示它 |
| `--tracker`            | 启用的跟踪标签名称或 ID（可重复或以逗号分隔） |
| `--enable-module`      | 启用的模块：`boards`、`calendar`、`documents`、`files`、`gantt`、`issue_tracking`、`news`、`repository`、`time_tracking`、`wiki` |
| `--issue-custom-field` | 启用的工单级自定义字段名称或 ID（可重复）。名称仅匹配工单自定义字段 |
| `--custom-field`       | 项目自定义字段值，格式为 `name=value` 或 `id=value`（可重复；多值字段请对同一字段重复使用该标志，`name=` 表示清空）。参见[自定义字段值](/zh-cn/commands/issues/#自定义字段值)。名称仅匹配项目自定义字段 |

```bash
redmine projects create \
  --name "Platform" --identifier platform \
  --homepage https://platform.example.test \
  --tracker Bug,Feature \
  --enable-module issue_tracking,wiki,time_tracking
```

## update

```bash
redmine projects update <identifier> [flags]
```

所有标志均为可选；未提供的字段保持不变。

| 标志 | 描述 |
|------|------|
| `--name`               | 新项目名称 |
| `--description`        | 新描述 |
| `--description-file`   | 从文件读取新描述（`-` 表示读取标准输入）；与 `--description` 互斥；空文件或只含空白的文件会被拒绝（使用 `--description ""` 清空描述） |
| `--homepage`           | 新主页 URL |
| `--public`             | 设置为公开可见 |
| `--parent`             | 新父项目（标识符、名称或数字 ID）。空值表示从当前父项目中分离。 |
| `--inherit-members`    | 切换是否继承父项目成员 |
| `--default-assignee`   | 默认指派人（登录名、姓名或数字 ID）。空值会尝试清除（部分 Redmine 版本会忽略该清除操作）。 |
| `--default-version`    | 默认版本（名称或数字 ID）。空值会尝试清除（部分 Redmine 版本会忽略该清除操作）。 |
| `--default-issue-query` | 作为项目默认问题列表的公共查询（名称或 ID；同名时本项目的查询优先于全局查询）。空值表示清除。<Badge text="Redmine 5.0+" variant="note" /> 旧版本会忽略该设置；`projects get` 不会显示它 |
| `--tracker`            | 替换启用的跟踪标签集合 |
| `--enable-module`      | 替换启用的模块集合 |
| `--issue-custom-field` | 替换工单级自定义字段集合 |
| `--custom-field`       | 项目自定义字段值，格式为 `name=value` 或 `id=value`（可重复；多值字段请对同一字段重复使用该标志，`name=` 表示清空）。参见[自定义字段值](/zh-cn/commands/issues/#自定义字段值)。名称仅匹配项目自定义字段 |

<Aside type="note">
  `--tracker`、`--enable-module` 和 `--issue-custom-field` 在提供时会替换当前集合，需要传入完整列表，而不仅是要新增的项。
</Aside>

## archive

<Badge text="Redmine 5.0+" variant="note" />
```bash
redmine projects archive <identifier> [flags]
```

| 标志 | 描述 |
|------|------|
| `-f, --force` | 跳过确认提示 |

已归档的项目会从默认项目列表中隐藏，在恢复之前无法编辑。

## unarchive

<Badge text="Redmine 5.0+" variant="note" />
```bash
redmine projects unarchive <identifier>
```

恢复先前归档的项目，使其再次出现在默认列表中。

## delete

<Badge text="危险操作" variant="caution" />
```bash
redmine projects delete <identifier> [flags]
```

| 标志 | 描述 |
|------|------|
| `-f, --force` | 跳过确认提示 |

<Aside type="caution">
  删除项目将同时移除其所有工单、工时记录和成员关系，且无法撤销。
</Aside>

## members

```bash
redmine projects members <identifier> [flags]
```

列出项目的所有成员及其角色。
