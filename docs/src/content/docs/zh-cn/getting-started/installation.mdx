## 安装

<Tabs syncKey="installer">
  <TabItem label="Homebrew" icon="apple">
    适用于 macOS 和 Linux，包含 shell 补全。

    ```bash
    brew install aarondpn/tap/redmine
    ```
  </TabItem>

  <TabItem label="安装脚本" icon="seti:shell">
    适用于 macOS 和 Linux，安装到 `~/.local/bin`。

    ```bash
    curl -fsSL https://raw.githubusercontent.com/aarondpn/redmine-cli/main/install.sh | bash
    ```
  </TabItem>

  <TabItem label="PowerShell" icon="seti:powershell">
    适用于 Windows，安装到 `%LOCALAPPDATA%\Programs\redmine-cli` 并加入 `PATH`。

    ```powershell
    irm https://raw.githubusercontent.com/aarondpn/redmine-cli/main/install.ps1 | iex
    ```
  </TabItem>

  <TabItem label="手动安装" icon="download">
    从 [GitHub Releases](https://github.com/aarondpn/redmine-cli/releases/latest) 下载适合你平台的压缩包，并将 `redmine` 放到 `PATH` 中。
  </TabItem>
</Tabs>

确认可以运行，然后[登录](/zh-cn/getting-started/configuration/)：

```bash
redmine --version
```

## 更新

```bash
redmine update
```

通过 Homebrew 安装时使用 `brew upgrade` 更新。Docker 镜像需拉取后重新创建容器（或重启 MCP 客户端）：`docker pull ghcr.io/aarondpn/redmine-mcp`，或 `docker compose pull && docker compose up -d`。详见[自更新](/zh-cn/commands/other/#自动更新)。

## 脚本选项

两个安装脚本都会校验发布版本的校验和；若安装了已登录的 [GitHub CLI](https://cli.github.com)，还会验证构建证明。运行脚本前可设置以下环境变量：

| 变量 | 作用 |
|---|---|
| `REDMINE_CLI_VERSION` | 安装指定版本，例如 `v2.17.0` |
| `REDMINE_CLI_SKIP_ATTESTATION=1` | 跳过构建证明检查（不推荐） |
| `REDMINE_INSTALL_DIR` | 安装到其他目录 |
| `REDMINE_CLI_NO_MODIFY_PATH=1` | 仅 PowerShell：不修改 `PATH` |

变量要传给运行脚本的 shell，而不是 `curl`：

```bash
curl -fsSL https://raw.githubusercontent.com/aarondpn/redmine-cli/main/install.sh | REDMINE_CLI_VERSION=v2.17.0 bash
```

```powershell
$env:REDMINE_CLI_VERSION = 'v2.17.0'; irm https://raw.githubusercontent.com/aarondpn/redmine-cli/main/install.ps1 | iex
```
